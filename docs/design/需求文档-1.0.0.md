# BlackBoxProFabric 需求文档 v1.0.0

## 1. 项目概述

### 1.1 项目名称
BlackBoxProFabric

### 1.2 项目定位
基于 Minecraft Fabric 1.21.11 的客户端 Mod，作为 Bukkit/Spigot/Paper 服务端插件的**自动化功能测试工具**。

通过接收服务端下发的 Plugin Message 指令，在客户端模拟真实玩家的全部行为（移动、交互、GUI 操作、战斗等），实现对服务端插件逻辑的黑盒测试。

### 1.3 技术栈
| 项目 | 版本/说明 |
|---|---|
| Minecraft | Java Edition 1.21.11 |
| Mod Loader | Fabric |
| Fabric API | 对应 1.21.11 最新稳定版 |
| 语言 | Kotlin (fabric-language-kotlin) |
| 构建工具 | Gradle (Kotlin DSL) |
| 通讯协议 | Minecraft Plugin Message Channel (Custom Payload) |

### 1.4 架构概览
```
┌─────────────────────┐         Plugin Message          ┌─────────────────────┐
│   Bukkit Server     │ ──────────────────────────────▶  │  BlackBoxProFabric Mod │
│   (测试控制端)       │  Channel: blackbox:command       │  (客户端执行端)      │
│                     │ ◀──────────────────────────────  │                     │
│                     │  Channel: blackbox:response      │                     │
└─────────────────────┘                                  └─────────────────────┘
```

## 2. 通讯协议设计

### 2.1 Channel 定义
| Channel ID | 方向 | 用途 |
|---|---|---|
| `blackbox:command` | Server → Client | 服务端下发行为指令 |
| `blackbox:response` | Client → Server | 客户端回报执行结果 |

### 2.2 消息格式
采用 JSON 文本编码，通过 `CustomPayload` 传输。

#### 指令消息 (Server → Client)
```json
{
  "id": "uuid-string",
  "action": "action_type",
  "params": { ... },
  "delay": 0
}
```
| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 指令唯一 ID，用于结果回报关联 |
| `action` | String | 行为类型标识，见第 3 章 |
| `params` | Object | 行为参数，因 action 而异 |
| `delay` | Long | 延迟执行毫秒数，默认 0 |

#### 响应消息 (Client → Server)
```json
{
  "id": "uuid-string",
  "status": "success | failure",
  "message": "可选的描述信息",
  "data": { ... }
}
```

| 攻击实体(完整) | `attack` | 自动完成：look → swing → attack_entity |

## 5. 非功能性需求

### 5.1 线程安全
- 所有涉及 Minecraft 客户端状态的操作必须在客户端主线程（Render Thread）执行
- 网络消息接收后通过 `MinecraftClient.getInstance().execute {}` 调度到主线程

### 5.2 错误处理
- 每个 Action 执行失败时必须通过 `blackbox:response` 回报错误信息
- 不得因单个指令失败导致 Mod 崩溃或断开连接

### 5.3 日志
- 所有收到的指令和执行结果需记录日志
- 支持通过配置文件控制日志级别

### 5.4 兼容性
- Mod 仅作为客户端 Mod 运行，不要求服务端安装
- 服务端通过标准 Plugin Message API 发送指令即可，无需额外依赖

## 6. Bukkit 服务端对接示例

服务端插件通过标准 Plugin Message API 向客户端发送指令：

```kotlin
// Bukkit 服务端注册 Channel
Bukkit.getMessenger().registerOutgoingPluginChannel(plugin, "blackbox:command")
Bukkit.getMessenger().registerIncomingPluginChannel(plugin, "blackbox:response") { channel, player, data ->
    val json = String(data, Charsets.UTF_8)
    // 处理客户端回报
}

// 发送指令
fun sendAction(player: Player, action: String, params: JsonObject) {
    val json = JsonObject().apply {
        addProperty("id", UUID.randomUUID().toString())
        addProperty("action", action)
        add("params", params)
        addProperty("delay", 0)
    }
    player.sendPluginMessage(plugin, "blackbox:command", json.toString().toByteArray(Charsets.UTF_8))
}
```
